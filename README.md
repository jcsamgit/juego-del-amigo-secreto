Este es un juego sencillo basado en un codigo simple!
No trae dependencias, ni librerias ni framework, solo html css y js

Es muy facil de entender y no requiere mucha complejidad en los algoritmos

Solo hay 3 funciones basicas, la funcion "agregar amigo" que ademas de añadir amigos a la lista tambien filtra los datos ingresados de manera que solo se pueda ingresar letras. Luego la funcion "mostrar amigo" permite que se pueda visualizar los nombres en pantalla a medida que se vayan agregando. Por ultimo esta la funcion "sortear amigo" que permite elegir aleatoriamente un nombre de la lista para saber quien es el amigo secreto y luego lo muestra en pantalla, al mismo tiempo esta funcion impide que se pueda sortear si la ista esta vacia
